# Plans

Implementation plans for the Vitrola Mp3 Android app. Each plan lists phases, tasks, done criteria and the maintainer checkpoints.

| Plan | Scope | Status |
|---|---|---|
| [001-android-app-v1.md](001-android-app-v1.md) | First complete version of the Android app (phases 0–8) | Ready to start |

Conventions:
- One file per plan: `NNN-short-name.md`, newest number last.
- Tick tasks (`- [x]`) and fill the plan's progress log as you go, committing with the work.
- If the plan changes, edit it in place and note why in the progress log; new decisions also go to `docs/decisions/` as ADR files.
